POLÍTICA DE PRIVACIDAD

LUCK XIT procesa los enlaces que introduces para generar vistas previas y solicitar descargas.

El historial y la lista de descargas se guardan en el almacenamiento local de este navegador. No se sincronizan automáticamente entre dispositivos.

El servidor puede recibir el enlace, la dirección IP y datos técnicos necesarios para atender la solicitud y mantener la seguridad del servicio.

No introduzcas enlaces privados ni información personal. Utiliza el servicio únicamente con contenido que tengas derecho o autorización para descargar.

Los servicios de terceros que alojan el contenido pueden aplicar sus propias políticas de privacidad.
